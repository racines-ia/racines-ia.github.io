# Collège La Rivière

Application de gestion de l'école : appel, cahier de cotes, bulletins officiels, palmarès, rapports aux parents, présence du personnel.

- En ligne : https://racines-ia.github.io
- Données : Supabase (`supabase/schema.sql`, fonctions `supabase/functions/ecole-compte` et `ecole-ia`)
- IA : Google Gemini, via la fonction `ecole-ia`
